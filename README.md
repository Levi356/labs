# Labs

Personal lab notebook for virtual and hands-on work. 

### Goal:  document everything I touch

## Structure

- **virtual-lab/** — Docker, VMs, Wireshark, packet captures, protocols, networking tools.
- **hands-on-lab/** — physical switches, routers, racks, RAID, hardware configs.

Old student homework lives in other repos. This one is only for deliberate practice and notes.

## How to use

Every session: drop a dated markdown note in the relevant `notes/` folder. Keep it raw. What you did, what you saw, what broke, what you learned.
